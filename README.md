# 🧠 Interactive Quiz

A responsive web-based quiz application that allows users to answer questions, receive immediate feedback and track their scores.

## ✨ Features

* Dynamic questions
* Multiple-choice answers
* Answer validation
* Score calculation
* Interactive UI
* Responsive design

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/sailikita123/interactive-quiz.git
cd interactive-quiz
```

Open `index.html` in your browser.
